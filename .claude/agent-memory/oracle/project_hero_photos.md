# Hero — Fotos provisórias a substituir

**Situação atual:** Hero usa `servidor-rack-hpe.jpg` (principal) e `rack-furukawa.jpg` (secundária). São fotos reais de campo mas tiradas de forma casual, não para o site.

**Decisão:** Jaison confirmou que as fotos atuais são provisórias. Futuramente serão trocadas por fotos "que vendam mais."

**Why:** Fotos profissionais (técnico olhando para câmera, ambiente limpo e iluminado, equipe em ação com uniforme) convertem melhor do que fotos de campo casuais. O contexto visual do hero é a primeira impressão para o cliente B2B.

**How to apply:** Quando o Jaison mencionar novas fotos para o site, priorizar o hero como destino principal. As fotos ideais:
- Técnico com uniforme UP Tech, postura profissional, olhando para câmera (ou para equipment)
- Ambiente limpo, iluminado — sala de servidores arrumada ou técnico em campo com EPI completo
- Resolução mínima 1280x960 para não pixelar no hero 4:3
- Evitar: escada laranja, cabos no chão, ambiente desorganizado, fotos de costas

**Arquivos atuais a substituir:**
- `src/assets/photos/servidor-rack-hpe.jpg` → foto principal hero
- `src/assets/photos/rack-furukawa.jpg` → foto secundária hero (168x168px crop)
